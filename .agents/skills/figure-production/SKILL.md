# Figure Production Skill

## When to Trigger
- Trigger whenever authoring scripts that generate or export plots in MATLAB (`matlab/analytical/`, `matlab/simulink/`).
- Active in Task 1.2 (steady-state and $V/f$ curves), Tasks 3.1–3.3 (transient waveforms), and Task 4.1 (report collation).
- Target output directory: `out/figures/*.png` (or `.svg`).

## Styling Standards
All figures generated by MATLAB scripts must adhere to publication standards:
- **Renderer**: Painters / Vector export (`exportgraphics(fig, 'path.png', 'Resolution', 300)`).
- **Fonts**: Helvetica or Times New Roman, minimum font size 10 pt (labels 11 pt, titles 12 pt).
- **Interpreters**: LaTeX interpreter for mathematical symbols ($\tau$, $\omega$, $\phi$, $\eta$, $\Delta$).
- **Grid**: `grid on; grid minor; box on;`.
- **Line Widths**: Main signals $\ge 1.5$ pt; nominal operating markers with distinct symbols (e.g. `ko` with `'MarkerFaceColor', 'r'`).

## Required Steady-State Plots (Part 1)
1. **Torque vs. Speed ($T \times n$)**: Speed from $0$ to $n_s = 1800\text{ rpm}$. Mark nominal torque $T_{nom} = 20.60\text{ N}\cdot\text{m}$ at $n_{nom} = 1715\text{ rpm}$ and breakdown torque $T_{max}$ at $s_{max}$.
2. **Stator Line Current vs. Speed ($I_s \times n$)**: Mark starting current $I_{start}$ ($s=1$) and nominal current $I_{line,nom} = 14.0\text{ A}$.
3. **Active Power vs. Speed ($P_a \times n$)**: Plot input active power $P_{elec}$ and developed mechanical power $P_{mec}$. Mark $P_{nom} = 3.7\text{ kW}$.
4. **Power Factor vs. Speed ($\cos\phi \times n$)**: Mark nominal power factor $\cos\phi = 0.81$.
5. **Efficiency vs. Speed ($\eta \times n$)**: Mark nominal efficiency $\eta = 85.5\%$.
6. **Scalar $V/f$ Family ($T \times n$)**: Overlay 4 curves ($100\%$, $75\%$, $50\%$, $25\%$) on a single figure, demonstrating invariant breakdown torque and synchronous speed shift.
