## 1. Technical Hurdles & Failure Modes Encountered
- **Initial Velocity Anomaly in Library Subsystem:** Initial inspection showed motor running at ~9.4 rpm ($1\text{ rad/s}$) at $t=0.01\text{ s}$ with nearly zero torque ($0.4\text{ N}\cdot\text{m}$). Investigation revealed two coupled root causes:
  1. `Machine Inertia` had default `initialization_option = 2` (`fElectrical0 = 60`), forcing synchronous speed initialization ($\omega_0 = 188.5\text{ rad/s}$) rather than standstill ($s=1.0$).
  2. Subsystem measurement conversion gains (`pu2si_wm`, `pu2si_Te`) defaulted to `1.0`, meaning measurement bus exported raw per-unit values ($1.0\text{ p.u.}$) which was multiplied by $30/\pi \approx 9.55$, creating an erroneous reading of $9.55\text{ rpm}$ when the motor was actually already at synchronous speed ($1800\text{ rpm}$).
- **Parameter Promotion & Mask Link Integrity:** Attempting to unlink the block (`LinkStatus = 'none'`) caused `elec.conv.AsynchronousMachineSIUni` callbacks to drop mask evaluation, resulting in `Unrecognized function or variable 'SRated'`. Resolved by keeping the library link intact and assigning promoted mask parameters (`pu2si_wm = omega_s`, `pu2si_Te = P_nom_W / omega_s`, `fElectrical0 = '0'`, `wrm0 = '0'`) directly on the subsystem mask.
- **Bench Inertia Time Horizon Reality:** Coupled bench moment of inertia ($J = 0.701\text{ kg}\cdot\text{m}^2$) requires $4.0\text{ to }4.5\text{ s}$ for full acceleration from standstill to no-load steady state ($\sim 1774\text{ rpm}$). Parameterized `run_sim_harness` to allow flexible timing overrides (`StopTime`, `StepTime`).

## 2. Gauntlet Audit Trail
### Iteration 1 Verdict: APPROVE
- **Findings:**
  - Mathematical locked-rotor derivation ($s=1.0$) verified against Table 2.4 and ADR-001: $Z_{in}(s=1) = 2.2308 + j5.1649\,\Omega$ ($|Z_{in}| = 5.6261\,\Omega$), $I_{line,start} = 67.73\text{ A RMS}$, $P_{ag,start} = 4778.9\text{ W}$, $T_{start} = 25.35\text{ N}\cdot\text{m}$.
  - Simulation harness correctly routes all Phase 3 operational modes (`dol_startup`, `nominal_step`, `regenerative`) with standstill initialization ($\omega_0 = 0$) and base SI units.
  - Advisory 1: For Phase 3 steady-state settlement, use $t_{stop} \ge 5.0\text{ s}$ for `dol_startup` and $t_{step} \ge 4.5\text{ s}, t_{stop} \ge 7.0\text{ s}$ for `nominal_step`/`regenerative`.
  - Advisory 2: Document transient DC offset inrush peak ($121.25\text{ A}$) versus steady-state fundamental RMS ($67.73\text{ A RMS}$).

## 3. Key Architectural Takeaways for Future Sessions
- Standstill DOL starting requires both `fElectrical0 = '0'` and `wrm0 = '0'` on `Asynchronous_Machine` mask to prevent non-zero initial speed.
- Simscape Asynchronous Machine measurement bus outputs must always be scaled by base factors (`pu2si_wm = omega_s`, `pu2si_Te = P_nom_W / omega_s`).
- Sub-second MATLAB execution via persistent tmux IPC (`matlab_worker`) completely eliminates the 10-15s JVM startup delay for interactive test runs.
