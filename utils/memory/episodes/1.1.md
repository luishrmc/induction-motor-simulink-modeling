## 1. Technical Hurdles & Failure Modes Encountered

1. **Bench Rotational Drag vs. Nameplate Catalog Discrepancy:**
   - **Hurdle:** The consolidated laboratory baseline (Table 2.4 and Section 2.4 of `LAB_CONV_RLT_08_09_10.pdf`) specifies a coupled motor-generator bench with viscous friction $B = 0.0426\text{ N}\cdot\text{m}\cdot\text{s/rad}$ and equivalent inertia $J = 0.701\text{ kg}\cdot\text{m}^2$.
   - **Finding:** At rated speed ($n = 1715\text{ rpm}$, $\omega_m = 179.59\text{ rad/s}$), viscous rotational drag absorbs $P_{rot} = B\omega_m^2 = 1374.0\text{ W}$. Omitting this loss would report developed electromagnetic power ($P_{em} = 4482.3\text{ W}$) rather than useful shaft power. Conversely, reporting only shaft output ($P_{shaft} = 3108.3\text{ W}, \eta = 61.98\%$) appears inconsistent with the bare-motor catalog rating ($3.7\text{ kW}, \eta = 85.5\%$).
   - **Resolution:** Established the dual-metric convention (ADR-001/ADR-003). The analytical engine computes and reports both electromagnetic metrics ($T_{em} = 24.96\text{ N}\cdot\text{m}, P_{em} = 4482.3\text{ W}, \eta_{em} = 89.38\%$) and net shaft metrics ($T_{shaft} = 17.31\text{ N}\cdot\text{m}, P_{shaft} = 3108.3\text{ W}, \eta_{shaft} = 61.98\%$), cleanly reconciling catalog nameplate ratings against coupled laboratory bench drag.

2. **Phase vs. Line Voltage and Impedance Consistency:**
   - **Hurdle:** Under Delta ($\Delta$) stator connection at $V_{LL} = 220\text{ V}$, phase voltage equals line voltage ($V_{ph} = V_{LL}$), while stator line current is $I_{line} = \sqrt{3} I_{ph}$.
   - **Resolution:** Implemented exact complex impedance calculations:
     $Z_{in} = Z_1 + (Z_m \parallel Z_2') = 19.22 + j13.68\,\Omega$ ($|Z_{in}| = 23.59\,\Omega$, $\phi = 35.44^\circ$), yielding $I_{ph} = 9.33\text{ A}$ RMS, $I_{line} = 16.15\text{ A}$ RMS, and $\cos\phi = 0.8147$ (matching catalog nameplate $0.81$ with $< 0.6\%$ error).
