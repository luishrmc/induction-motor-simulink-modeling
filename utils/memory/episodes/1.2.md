## 1. Technical Hurdles & Failure Modes Encountered

1. **Breakdown Torque ($T_{max}$) Occlusion by Legend Box:**
   - **Hurdle:** In the initial generation of `out/figures/torque_vs_speed.png` and `out/figures/vf_scalar_family.png`, legends were placed at `'Location', 'northeast'` with tightly bounded $y$-limits ($[0, 62.8]\text{ N}\cdot\text{m}$).
   - **Failure Mode:** The peak breakdown operating point ($T_{max} = 54.63\text{ N}\cdot\text{m}$ at $n(T_{max}) = 1405.1\text{ rpm}$) and its magenta star marker were completely hidden underneath the opaque legend box, violating academic delivery specifications (`sim_proj.pdf` Part 1 Item E).
   - **Resolution:** Moved legends to `'Location', 'northwest'`, where low-speed torque ($n \in [0, 600]\text{ rpm}$, $T < 30\text{ N}\cdot\text{m}$) leaves open canvas clearance. Expanded vertical headroom to $70\text{ N}\cdot\text{m}$ (Figure 1) and $72\text{ N}\cdot\text{m}$ (Figure 6), making all peak operating points 100% visible.

2. **Portuguese String Truncation in LaTeX Legends:**
   - **Hurdle:** In Figures 3 and 4, catalog legend entries were authored as `sprintf('Pot\\^encia ...')` and `sprintf('Fator de Pot\\^encia ...')`.
   - **Failure Mode:** MATLAB's LaTeX parser dropped everything following unbraced circumflex tokens, truncating legend entries to literally `Pot` and `Fator de Pot`.
   - **Resolution:** Replaced unbraced circumflexes with scoped curly braces: `Pot\^{e}ncia` and `Fator de Pot\^{e}ncia`, rendering clean accented characters without truncation.

3. **Unrendered Raw LaTeX in Axes Titles:**
   - **Hurdle:** Root defaults configured `defaultTextInterpreter = 'latex'`, but MATLAB `Axes` objects lack a `TitleInterpreter` property. Consequently, titles defaulted to the TeX interpreter.
   - **Failure Mode:** TeX failed to compile LaTeX math tokens (`$\times$`, `\text{ V}`), causing all 6 figures to display raw backslashes and markup on top.
   - **Resolution:** Explicitly passed `'Interpreter', 'latex'` directly into every `title()`, `xlabel()`, and `ylabel()` call, using clean math mode expressions like `($220\ \mathrm{V},\ 60\ \mathrm{Hz}$)`.

4. **Bash Variable Expansion in Headless CLI Calls:**
   - **Hurdle:** Running `matlab -batch "title(..., '$220\text{ V}$');"` in bash inside double quotes caused bash to interpret `$2` and `$n` as environment variables, stripping characters from the command.
   - **Resolution:** Standardized CLI executions by invoking dedicated entry scripts (`run('matlab/analytical/run_analytical_sweeps.m'); exit;`) rather than embedding inline LaTeX strings inside shell strings.

## 3. Key Architectural Takeaways for Future Sessions

1. **Anti-Occlusion Policy for Motor Curves:** Always evaluate curve morphology before placing legends. For induction machines where peak breakdown torque occurs near $0.7$–$0.9\,n_s$, never default to `'northeast'`; use `'northwest'` with $\ge 15\%$ headroom.
2. **Explicit LaTeX Scoping:** Never rely on root defaults for axes titles. Always pass `'Interpreter', 'latex'` explicitly to `title()`, `xlabel()`, and `ylabel()`.
3. **Accent Formatting in MATLAB Strings:** Always format LaTeX accents with braces (`\^{e}`, `\^{a}`, `\''i`) to prevent parser dropouts.
4. **Adversarial Gauntlet Value:** The independent visual and physical review by `technical-critic` caught deliverable-breaking visual flaws that automated linters (`matlab-lint.sh`) cannot detect.
